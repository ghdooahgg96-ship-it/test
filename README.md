# بوابة طلبات العملاء

صفحة واحدة (`index.html`) لاستقبال طلبات العملاء مثل تغيير اسم عداد الكهرباء.

- **طلب جديد:** يختار العميل الخدمة، يعبّئ بياناته، ويرفع المرفقات (صك الملكية، الهوية، الكروكي...).
- **لوحة الطلبات:** إحصائيات، بحث وتصفية، تغيير الحالة، ملاحظات وسجل.
- **دمج في PDF واحد:** صفحة غلاف بالبيانات وفهرس المرفقات، ثم كل الصور وملفات PDF بترتيب ثابت.

التشغيل: افتح `index.html` في المتصفح. البيانات تُحفظ محلياً في المتصفح (IndexedDB).
لتعديل الخدمات أو المستندات المطلوبة: عدّل `SERVICES` و `DOCS` في أعلى السكربت.
